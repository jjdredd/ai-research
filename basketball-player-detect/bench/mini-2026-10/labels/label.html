How to label — read once, then collapse
  1. Work one sequence at a time. Each dark panel is one video sequence (~10 rows). Every row shows the same tracked player in up to 5 crops, taken at different frames (largest / most visible first). All crops in a row are guaranteed to be the same person — that is what the ground-truth track IDs tell us.
  2. Team (required). Look at the jersey colour across the row's crops. Players on the same team share the same jersey colour. Assign a short label per colour: T1, T2, and so on. The labels only need to be consistent inside one sequence (all white-jersey players → T1, all dark → T2, in that sequence). It does not matter which team is T1 vs T2. If a third kind of person appears (officials in stripes, coaches in suits), give them their own label (e.g. T9) and also tick Non-player.
  3. Number. Look at all crops; type the jersey number if readable in at least one. Two digits are normal (0–55). If you cannot read it confidently, leave it blank — blank is useful data (the OCR metric then ignores this track). Don't guess. If two crops seem to show different digits, the track's identity may be wrong: write idswitch? in the note field.
  4. Non-player checkbox. Tick it if this track is not an active player (referee, coach, seated bench player who wandered into frame, mascot, camera person). Referee stripes are usually obvious: vertical black/white.
  5. Note field. Free text for anything odd: partial occlusion, ball boy, jersey number on front not back, motion blur, suspected tracker id-switch, etc.
  6. Progress is automatic. Every edit is saved in this browser immediately (localStorage). You can close the tab and re-open the same label.html to continue — labeled rows dim and Next incomplete scrolls you onward. Keep using the same browser and file location, or your progress is lost. (If you must switch machines, Export CSV before leaving and ask the assistant to pre-load it.)
  7. When all 30 sequences are done (or any time to checkpoint): press Export CSV. It downloads track_attrs_all.csv. Move that file to basketball-player-detect/bench/mini-2026-10/labels/track_attrs_all.csv and tell the assistant "labels exported" — it will run bench/ingest_labels.py to validate and split them into per-sequence files, then continue the pipeline work.
  8. Quality bar: a wrong team label is worse than an honest blank+note. If a player's jersey is ambiguous (light grey between teams), label it and note ambiguous.
Estimated time: 3–5 min per sequence × 30 ≈ 1.5–2.5 h total. Taking breaks is fine — state persists.
